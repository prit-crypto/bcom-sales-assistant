# BCOM Sales Assistant (POC)

A proof of concept for **BCOM Global franchise partners**: upload a prospect's courier invoice, see the savings
against BCOM's rates, and send a branded proposal PDF and WhatsApp message.

The backend and the frontend are separate projects, each with its own README and Docker setup:

| Folder | What it is | Start here |
|---|---|---|
| [backend/](backend/) | The API: invoice reading, pricing, proposal PDF, WhatsApp message, saved proposals, customer link | [backend/README.md](backend/README.md) |
| [frontend/](frontend/) | The partner screens and the customer's page | [frontend/README.md](frontend/README.md) |

The agreed scope is in [docs/PLAN.md](docs/PLAN.md).
